Reproduce and interpret

From the validated source folder, run npm run benchmark:algorithms. Results are written to algorithm-leaderboard.json. No network or backend is required. Changing the experiment or hardware changes the results; this page is a static snapshot, not a live speed claim. A tie at the check interval does not establish a true iteration-level tie.
