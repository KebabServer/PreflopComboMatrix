DCFR is the default established algorithm. CFR+ remains available under Legacy algorithms as the verified baseline; Scheduled DCFR, its cubic hybrid, and cubic-averaging DCFR are experimental candidates. Additional experimental variants are hidden by default, not deleted. All GTO algorithms use the same exact Nash exploitability check. The convergence benchmark is workload-specific and is not a guarantee that any variant will be faster on your game.

          
Low-temperature, entropy-regularized QRE favors near-GTO play while keeping rare actions possible. Default 0.05% of pot. Higher temperatures can deliberately change strategy and increase exploitability. Both ordinary Nash exploitability and the regularized QRE gap must meet the target. Independent model; not GTO Wizard's proprietary solver.

Betting settings

            

            
Flop

              

              

              

              
Flop donks are first-to-act OOP leads when IP was the preflop aggressor. Select the preflop aggressor for a standalone flop solve; only the OOP opening bet uses donk sizing.

              

            

            
Turn

              

              

              

              
A donk bet is an OOP lead after IP was the last aggressor on the flop. Flop-mode solves detect this automatically. With a turn-only board, select the preceding flop action above. Blank donk sizes disable percentage-based donks; all-ins are controlled separately.

              

            

            
River

              

              

              

              
River donks apply when IP was the last aggressor on the turn. Flop/turn-mode trees detect this automatically; river-only solves use the preceding-turn selector.

              

            

            

            
Flop sampling is an approximation of the full game. Increase samples for better coverage, or use 49 turns × 48 rivers for full enumeration (requires substantially more memory and time).

            

            
            
            
            
River symmetry applies only when the fixed board and both weighted ranges allow suit permutations. Flop symmetry requires an invariant sampled runout set; otherwise it safely disables itself.

            

              
              

              

              
Culls an entire bet/raise size at each decision node when its range-weighted frequency falls below the cutoff (not a per-hand threshold). Culled actions become 0% for all hands and disappear from the action cards. Every 50/100/250 iterations, all sizes are reconsidered and can return. Check/fold/call/all-in remain available. Full-tree exploitability is still measured against every legal action, including culled sizes. This approximate GTO mode can use native scalar/SIMD WebAssembly when supported; otherwise it uses the JavaScript reference path.

            

            
            
            
Donk sizes apply only to eligible OOP flop, turn and river opening leads (not IP bets or raises). Use commas for multiple sizes (e.g. 33, 75). Blank bet or raise fields disable only that action type. Raises add the chosen percentage of the pot after calling, subject to the minimum legal raise. Max raises limits raises per street (0 = none); all-ins are separate.
